# Краткие docstring

Docstring объясняет назначение объекта или действие операции понятными читателю словами. Обычно достаточно одного предложения; существенные условия использования добавляй отдельно. Не пересказывай сигнатуру и структуру класса и не приписывай неподтверждённые гарантии. Формулировку выбирай по реальному назначению объекта.

| Объект | Docstring |
| --- | --- |
| `HttpSender` | `"""Проверяет ожидаемый HTTP-код."""` |
| `TokenProvider`, который хранит и обновляет токены | `"""Хранит и обновляет токены авторизации."""` |
| API-метод получения страницы регионов | `"""Возвращает страницу справочника регионов."""` |
| `RegionListItemResponseDto` | `"""Регион присутствия оператора."""` |
| `RegionListResponseDto` | `"""Список регионов с данными о странице."""` |

Для DTO применяй [отдельные правила docstring и описаний полей](dto.md#docstring-и-описания-полей): у каждого класса собственный docstring на русском, включая наследников, а поля Pydantic DTO имеют описания через `Field(description=...)`.
