# Техническое исследование

Установи исследуемый вопрос из запроса, PRD или другого указанного источника. Прочитай применимые инструкции, связанный код, зависимости и ограничения. Если данных для определения вопроса недостаточно, уточни его; PRD не обязателен.

Сопоставь подходящие альтернативы, включая существующий механизм проекта, если он пригоден. Определи критерии по задаче: совместимость, сложность, эксплуатацию и, когда применимо, стоимость, лицензии, безопасность и производительность. Не добавляй непригодную альтернативу ради количества; объясни ограниченность выбора.

Для изменчивых технических фактов проверяй первичные источники, версии и дату проверки. Отделяй факт, вывод и неизвестное. Для существенного неопределённого риска при необходимости проведи изолированный воспроизводимый эксперимент без изменения рабочих зависимостей или данных; фиксируй команды, результат и ограничения. Не объявляй незапущенный эксперимент проверкой.

Оформи результат по [шаблону](references/template.md) или принятому формату. Предложение не является принятым решением; учитывай уже принятые решения и порядок согласования. Сохраняй документ по указанному пути или конвенции проекта, не перезаписывая чужие файлы; если путь и конвенция не определены, представь результат в ответе. Исследование само по себе не разрешает реализацию или внешние записи.
