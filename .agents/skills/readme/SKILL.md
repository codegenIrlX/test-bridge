# README проекта

Создавай, обновляй или дополняй README только по прямому запросу пользователя. Устаревшие сведения, обнаруженные в другой задаче, сообщи пользователю; самостоятельно README не меняй.

Изучи инструкции проекта, существующий README, код, конфигурацию и другие достоверные источники. Определи аудиторию и язык по запросу и проекту. Команды, зависимости, настройки, возможности и ссылки описывай по подтверждённым данным; недостающие важные сведения уточняй. Не включай секреты и персональные данные.

Подготовь полный итоговый текст README с учётом существующего содержимого и покажи его пользователю до записи файла. Дождись явного согласования текста; если пользователь просит изменения, представь обновлённый полный текст для согласования. После согласования запиши именно согласованную версию и проверь ссылки, форматирование и обоснованность команд. Не запускай команды с побочными эффектами только ради документации без необходимого разрешения. Push и иная публикация требуют отдельного разрешения.

Используй [шаблон](assets/template.md) как основу: сохраняй подходящие разделы, порядок и уровень подробности адаптируй к проекту. Не добавляй пустые разделы или неподтверждённые сведения. Для частичного изменения сохрани существующую полезную информацию и всё равно покажи полный итоговый текст перед записью.
