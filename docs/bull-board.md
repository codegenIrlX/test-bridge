# Просмотр очереди обработки Allure

Bull Board доступен на хосте платформы по адресу `http://127.0.0.1:3001`. Панель показывает очередь `ALLURE_IMPORTS_QUEUE`, состояния задач и идентификатор импорта. Сопоставить задачу с данными можно по `importId` в PostgreSQL и ответе API.

Панель работает в режиме чтения и слушает только loopback хоста. Для входа используйте имя `admin` и пароль `default.bull_board.password` из `secrets.yaml` выбранного окружения. Для доступа с других компьютеров потребуется защищённый прокси.

При обновлении существующей установки добавьте в `secrets.yaml` раздел `bull_board` с непустым `password` в `default` или выбранное окружение, затем выполните `docker compose up -d --build`. Если пароль не задан, подготовка панели завершится с ошибкой; подготовка PostgreSQL от него не зависит.

В Redis остаются до 100 завершённых и 100 неуспешных задач. При повторном запуске одного импорта его предыдущая терминальная задача с тем же идентификатором удаляется, чтобы можно было поставить новую. Очередь не заменяет PostgreSQL как источник состояния импорта; история в Bull Board ограничена сохранностью Redis и указанным пределом.
