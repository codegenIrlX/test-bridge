# Конфигурация и запуск

Платформа читает настройки из `config.yaml`, а пароль PostgreSQL и токен API — из `secrets.yaml`. Перед запуском создайте `secrets.yaml` по образцу `secrets.example.yaml` и задайте собственные значения. Не добавляйте этот файл в Git и не передавайте его в контекст сборки образа.

В обоих файлах раздел `default` задаёт общие значения, а раздел выбранного окружения переопределяет их. Вложенные объекты объединяются по ключам. Окружение выбирается переменной `METRICS_SRV_ENV`; без неё используется `development`. Оба файла должны содержать раздел выбранного окружения, даже если он пуст. При отсутствии или неверном значении обязательных параметров процесс завершает запуск с ошибкой.

`config.yaml` содержит адреса и порты PostgreSQL и Redis, путь к архивам, пределы размера и количества файлов, интервал работы Scheduler и списки `metrics.project_allowlist` и `metrics.suite_allowlist`. Только перечисленные проекты и наборы получают отдельные метки метрик; остальные объединяются в `other`, а отсутствующие — в `unknown`. Значения `other` и `unknown` зарезервированы. Списки по умолчанию пусты.

`secrets.yaml` содержит `database.password`, `api.token`, `bull_board.password`, `grafana.password` и отдельный `grafana.database_password` для чтения аналитических представлений. В Docker файл конфигурации монтируется только для чтения. Однократный контейнер читает Compose secret от имени root и копирует его в tmpfs с владельцем приложения и правами `0400`; остальным процессам tmpfs доступен только для чтения. Collector и Grafana получают отдельные файлы со своими секретами во временных томах. Локально приложение читает `secrets.yaml` из рабочего каталога; внутри контейнера используется `/run/secrets/secrets.yaml`.

После настройки файлов запустите платформу:

```sh
docker compose up -d --build
```

Compose запускает PostgreSQL, Redis, миграции, процессы приложения, OpenTelemetry Collector, VictoriaMetrics и Grafana. API доступен на порту 8000 хоста, Grafana — на `http://127.0.0.1:3000` с пользователем `admin` и паролем `grafana.password`. Данные PostgreSQL, Redis, входящие архивы, VictoriaMetrics и Grafana хранятся в именованных томах. Временные файлы секретов не включаются в образ. Для запуска требуются Linux-контейнеры.

Collector хранит очередь отправки в памяти. При его перезапуске точки, которые ещё не были отправлены, теряются. Следующие опросы восстановят текущие агрегаты из PostgreSQL, но не восполнят пропущенные точки истории.

После изменения `secrets.yaml` подготовьте копию командой `docker compose run --rm --no-deps secret-bootstrap`. Если изменился `api.token`, дополнительно выполните `docker compose run --rm --no-deps otel-auth-bootstrap`, затем перезапустите `api`, `scheduler`, `processor` и `otel-collector`. После перезапуска Docker daemon или хоста повторно выполните `docker compose up -d`: tmpfs может очиститься, а обычный `docker compose restart` не запускает однократные контейнеры подготовки.

Пароли PostgreSQL и администратора Grafana из YAML используются при первоначальном создании их хранилищ. Изменение YAML не меняет существующие учётные записи: при ротации нужно отдельно обновить пароль в соответствующей системе и секрет приложения. Именованные тома не заменяют резервное копирование.

После миграции `grafana-database-bootstrap` создаёт представления `testbridge_analytics` и отдельную роль `testbridge_grafana` с чтением только этих представлений. Для создания роли владелец подключения должен иметь право `CREATEROLE`; штатный пользователь PostgreSQL Compose им обладает. Подготовка проверяет права роли во всех пользовательских схемах, включая права через `PUBLIC`: доступ к другим таблицам и представлениям, последовательностям, пользовательским функциям или создание объектов приводит к ошибке запуска. Служебные схемы PostgreSQL при этой проверке исключаются. Существующие импорты и результаты сохраняются. После изменения `grafana.database_password` повторно выполните `secret-bootstrap` и `grafana-database-bootstrap`, затем перезапустите Grafana; подготовка обновляет пароль роли и файл источника вместе с остальной конфигурацией.
