# Дашборды Grafana для проектов TestBridge

Четыре дашборда с общим выбором проекта из `imports.project`, периодом по умолчанию в семь дней и ссылками, сохраняющими фильтры. Приёмка на рабочем TestBridge и в существующем Jenkins.

- [x] **Developer · Дашборды.** Опубликованы результаты Allure, качество прогонов, длительность и нестабильные тесты. Переменная проекта читается из PostgreSQL, ссылки передают проект и период.
- [x] **Tech-lead · Источник.** В рабочей PostgreSQL применена ревизия `0004_grafana_read_model`. Роль Grafana читает три представления. Проверено, что у неё нет доступа на чтение таблицы импортов и запись в таблицу тестов или представления, а также на создание объектов в `public`.
- [x] **Tech-lead · Проверка на сборке №37.** Сверены пять статусов (8, 1, 0, 0, 0), девять тестов в топе и максимальный P95 10,511 с. Пустой период вернул пять нулей. Проверка нестабильности на наборах строк показала два перехода для последовательности «успех, сбой, успех» и исключила другой проект. Пользователю отправлено сообщение, что Jenkins можно запускать.
- [x] **Tech-lead · Новый прогон.** Jenkins №40 получил HTTP `202`. Импорт `cb558157-8b4f-4c19-9c77-fdc5899627c0` завершён с первой попытки, 9 результатов и 51 шаг совпали с Allure ZIP по полям и вложенности. SHA-256 совпал с PostgreSQL, рабочий ZIP удалён. За последние 7 дней проект показал 3 прогона, 16 `passed`, 3 `failed`, остальные статусы — 0. Доля успехов 84,21 %, повторов внутри импортов 0, общий P50 — 0,030 с, P95 — 10,279 с. Нестабильные тесты по фактической истории не найдены.

В Playwright проверены проект, счётчики, порядок топа, подписи в легенде и переход на «Нестабильные тесты» с сохранением проекта и периода. Период без импортов проверен через API Grafana. Сейчас в БД один проект, разделение нескольких проектов проверено на контрольных строках. Ruff для приложения, deploy и тестов прошёл. Локально прошли 29 тестов конфигурации и парсера.
