# Скилл database-work для TestBridge

Цель — закрепить порядок работы со схемой, SQL, транзакциями и миграциями.
Задача охватывает скилл, справочник и правило в AGENTS.md. Основной сценарий
опирается на PostgreSQL и psycopg. Справочник применяется при работе с Alembic
и SQLAlchemy в проектах, где они уже используются.

## Практики из статьи

Источник — [Best Practices for Alembic and SQLAlchemy](https://medium.com/@pavel.loginov.dev/best-practices-for-alembic-and-sqlalchemy-73e4c8a6c205)
Павла Логинова.

1. Единый формат имён ограничений и индексов через `MetaData.naming_convention`.
2. Дата в имени файла через `file_template` для навигации. Порядок применения задаёт граф ревизий.
3. Комментарии к таблицам и колонкам в схеме БД и краткие описания миграций.
4. SQL или локальное описание таблицы на момент ревизии вместо зависимости от текущих ORM-моделей.
5. Stairway-тест `upgrade → downgrade → upgrade` для обратимых ревизий и план восстановления для необратимых.
6. Отдельный запуск миграций после готовности БД и старт приложения после их успеха.
7. Mixins для общих полей с одинаковой семантикой. Различение клиентских и серверных значений по умолчанию.
