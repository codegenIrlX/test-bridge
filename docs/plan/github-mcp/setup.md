Границы: настройки MCP и авторизация без сохранения секретов в репозитории; существующие изменения не затрагивать.

Критерии: определён доступный способ авторизации, подключение проверено запросом к профилю или указано, какое действие пользователя необходимо.

- [ ] Tech-lead: настроить подключение; файл: .codex/config.toml; зависимость: токен GitHub; проверка: список MCP и запрос профиля.
